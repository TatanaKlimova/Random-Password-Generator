# Random Password Generator

**Автор:** Климова Татьяна

## Описание

Приложение для генерации случайных паролей с графическим интерфейсом. Позволяет настраивать параметры пароля, сохранять историю сгенерированных паролей в JSON-файл и управлять ею.

## Возможности

- Генерация паролей длиной от 4 до 50 символов
- Выбор типов символов:
  - Заглавные буквы (A-Z)
  - Строчные буквы (a-z)
  - Цифры (0-9)
  - Специальные символы (!@#$%^&* и др.)
- Копирование пароля в буфер обмена
- Сохранение истории паролей в JSON
- Загрузка истории при запуске
- Очистка истории
- Экспорт истории в JSON-файл

## Требования

- Python 3.6 или выше
- Стандартные библиотеки Python (tkinter, random, string, json, os, datetime)
